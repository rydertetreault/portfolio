What should touching an agent card do?

Five interactive concepts on the same Living Map DAG canvas, same run data. Each makes the agent cards directly manipulable in a different way — Zapier/n8n-style. Click into each and judge how it feels to act on the run, not just watch it.

A

Card Config Flip

Every card flips into its own settings sheet — model, instructions, tools, context, retries — edited in place on the canvas. The Zapier "click a step to configure it" move.

Effort MZapier feel ●●●Graph mutation none
B

Edge Inserters + Palette

Hover an edge → a “+” appears on the wire. Pick an archetype (or describe one) and a new agent materializes into the flow. n8n's on-connection add, plus drag-to-depend ports.

Effort HZapier feel ●●●●Graph mutation full
C

Per-Card Run Controls

Run · Pause · Retry-with-edits · Skip · Pin on every card, plus a whole-graph dry-run mode. Zapier's "Test this step", generalized to live agents.

Effort MZapier feel ●●●Graph mutation status only
D

Data-Mapping Handles

Agents expose output chips — drag preview_url onto another card to bind it as {{deploy.preview_url}}. Zapier's field mapper made spatial; the why of every dependency becomes visible and editable.

Effort HZapier feel ●●●●●Graph mutation edges
E

Template Blocks

Marquee-select agents → save as a reusable block. A library panel of saved sub-flows you drag back onto any canvas. Zap templates ∕ Gumloop skills — and shareable to a course.

Effort H+Zapier feel ●●●Graph mutation bulk
F

Command Deck (A + B + D combined)

Selecting a card slides in a compact dock — steer, model & limits, tool toggles — and each tool row has a drag-handle you can fling onto any other card to wire it as a tool source. Plus edge + menus for insert/mute/boost, and fixed data-edge routing for same-column bindings.

Effort H+Zapier feel ●●●●●Graph mutation edges + tools
Suggested composition: B + A is the minimum set that reads as "Zapier for agents" — edge inserters to grow the flow, config flip to tune each node. C layers on cheaply; D and E build on B's mutation machinery. But judge by feel first — each demo is fully interactive on identical run data.
